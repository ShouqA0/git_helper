# Git Helper CLI 🛠️

A simple command-line tool built with C++ to help developers remember the sequence of Git commands.

I created this project to practice **C++ programming** and to understand how **Command Line Arguments (argc & argv)** work in real applications.

## 🚀 How to Build & Run

### 1. Compile the code
Since this is a C++ program, you need to compile it first using `g++`:

```bash
g++ git_helper.cpp -o githelper
```
### 2. Run the tool 
You can run the tool directly from your terminal by passing a command name:
`./githelper new`

## 📖 How to Use
Pass the action you want to perform as an argument:

> Start a new project:
`./githelper new`

> Push daily changes:
`./githelper push`

> Update local project:
`./githelper update`

> Create a branch:
`./githelper branch`

 `Learn the workflow. Trust the process. Build with confidence`
